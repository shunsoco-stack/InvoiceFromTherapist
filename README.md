# リラクゼーションサロン向け「施術記録 + 日払い計算」ミニシステム

紙でやっている「どのメニューを誰が施術したか」「その日のセラピスト日払い（歩合/固定）」を、入力→自動集計→CSV出力までできるローカルWebアプリです。

## できること（最小版）

- **セラピスト管理**: 名前・歩合（% or 固定円/件）を登録
- **メニュー管理**: メニュー名・単価を登録（必要ならメニュー別歩合で上書き）
- **施術入力**: 日付/セラピスト/メニュー/数量を入力（単価や歩合の上書きも可）
- **簡単入力（セラピスト向け）**: 大きいボタンで「セラピスト→メニュー→数量→保存」だけ（文字入力ほぼ無し）
- **日次レポート**:
  - セラピスト別の **売上合計 / 支払合計（日払い）** を自動計算
  - **支払い済み** 記録（取消も可）
  - **CSV出力**（Excelで開けます。UTF-8 BOM付き）

## 起動方法（ローカル）

Python 3.10+ 推奨。

```bash
cd /workspace
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py
```

起動したらブラウザで `http://localhost:5000` を開いてください。

セラピスト向けの簡単画面は `http://localhost:5000/kiosk` です。

ランディングページは `http://localhost:5000/lp` です。

## ロゴの表示（トップ画面）

トップ画面にロゴを表示したい場合は、`app/static/` に画像を置いてください。

- 自動検出: `logo.svg` / `logo.png` / `logo.webp` / `logo.jpg` / `logo.jpeg`
- 任意ファイル名を使いたい場合: 環境変数 `SALON_LOGO_FILENAME` で指定
- 代替テキストを変えたい場合: `SALON_LOGO_ALT` で指定

例:

```bash
export SALON_LOGO_FILENAME="shop_logo.png"
export SALON_LOGO_ALT="店舗ロゴ"
```

## データ保存場所

- SQLiteファイルは `data/salon.sqlite3` に保存されます。
- バックアップしたい場合は `data/` フォルダごとコピーしてください。

保存場所を変えたい場合は環境変数で指定できます:

```bash
export SALON_DB_PATH="/path/to/salon.sqlite3"
```

## 歩合の計算ルール

優先順位は以下です（上ほど優先）:

1. 施術入力の「歩合（上書き）」  
2. メニューに設定した「メニュー別歩合」  
3. セラピストの歩合（デフォルト）

計算方法:

- **%**: 支払 = 売上 × %（小数点以下は切り捨て）
- **固定**: 支払 = 固定円/件 × 数量

## よくある運用

- まず「セラピスト」「メニュー」を登録
- 毎日「施術入力」で記録
- 「日次レポート」で支払額を確認して、支払ったら「支払済にする」
- 必要ならCSVを印刷/保存
